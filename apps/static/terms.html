Using the store

APK STORE provides listings and downloads for independent Android applications approved by the store owner. Read each app's description and Android permission requests before installing it. Apps may have their own terms and privacy practices.

Downloads and updates

Downloads open in your browser. Android may ask you to permit installation from that source. APK STORE does not silently install or update other apps. A newer release generally needs the same package ID and signing certificate to install over an older version. Listings and files may change or be removed.

Publishing

Do not submit software that you lack the rights to distribute. Owner review is required before an app becomes public. Questions can be raised through the APK STORE repository.
